#+title: Excali DSL in Org Babel

* Setup

Build excali-mode with =make=, put the clone on =load-path=, and add this
configuration to your Emacs initialization file (not to the drawing block):

#+begin_src emacs-lisp :eval never
(with-eval-after-load 'org
  (org-babel-do-load-languages
   'org-babel-load-languages
   (cons '(excali . t)
         (assq-delete-all 'excali (copy-tree org-babel-load-languages)))))
#+end_src

In each =excali= block, press =C-c C-c= and confirm execution. The result
is a file link. Use =C-c '= to edit the source in Excali DSL mode and
=C-c C-x C-v= to toggle inline images. Outputs go into =output/= beside
this file; =:mkdirp yes= creates the directory.

* Editable native scene

Use =M-x excali-open= to open the generated =.excalidraw= file. It is a
scene, not an inline image. Regeneration replaces manual canvas changes.

#+begin_src excali :file output/editable.excalidraw :mkdirp yes :results file
node source "Source"
node result "Editable scene" right of source
edge source -> result
#+end_src
